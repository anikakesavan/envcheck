envcheck

Paste your .env and .env.example, see the drift instantly. Nothing is uploaded — this all runs in your browser.

How it works

Missing keys are ones present in .env.example but not your .env; empty keys exist in both but have no value set; extra keys are in your .env but not the example (often stale leftovers). "Fill in missing keys" appends any missing keys to your .env, copying the example's default, without touching anything you've already set.

Prefer the command line, or want this to run automatically in CI? pip install envcheck — see the README.
